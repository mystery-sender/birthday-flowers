🐙 GitHub Pages 3-Minute Step-by-Step:

  1. Log into your account at github.com.
  2. Click the green "New" button to create a new repository. Name it anything (for example: birthday-letter).
  3. Set the repository to Public, then click "Create repository".
  4. Click "uploading an existing file", drag and drop this file, and make sure its name is exactly: index.html.
  5. Click the green "Commit changes" button.
  6. Go to the repository Settings (top tab) → on the left sidebar click Pages.
  7. Under Branch, select main (or master), keep / (root), and click Save.
  8. Wait about 60 seconds! GitHub will show your live link at the top: https://<your-username>.github.io/birthday-letter.
